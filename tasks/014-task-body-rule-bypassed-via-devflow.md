# j-devflow 経由の起票で j-task の本文規則が適用されない

## 概要

`j-task` は本文を `## 概要` と `## 背景` だけに限り、分析・引用・実装方針・受け入れ基準を禁じている。
**しかし `j-devflow` などの流れの中で起票されるタスクは、この規則を通らずに作られる。**
fde では 043・049・050・051 と 046 の follow-up 4件が、規則を外れた本文で起票された。
**規則を守らせる経路を作るか、規則のほうを実態に合わせるかを決める。**
**方向づけ（2026-09-20、ユーザー）: 調査結果を一律で禁じる側には倒さない。** 起票時の事前調査をメモとして残せるようにし、実装セッションが「検証済みの結論」と受け取らない形にする。

## 背景

規則の目的は、実装者が起票者の問題理解に縛られないようにすることである。
**一方で外れた本文には根拠の引用と探索の手がかりが入っており、捨てると再取得に費用がかかる。**
