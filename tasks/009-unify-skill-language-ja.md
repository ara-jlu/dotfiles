# 自作スキルの記述言語を日本語に統一する

## 概要

`~/.claude/skills/` の自作スキル（`j-*` と `md2joifup`）で SKILL.md の記述言語が揃っていない。`j-recap` はほぼ日本語、他の8個はほぼ英語で、日本語が混じるのは出力文例や固有名詞の箇所に限られる。どちらかに統一したい。希望は日本語。

対象は自作スキルのみ。superpowers と ECC のスキルは無改変で使う方針なので触らない。

## 背景

CLAUDE.md には「機械が扱う面 = 英語、人が読む面 = 日本語」とあるが、スキル本文がどちらに当たるかは決めていない。統一の方向と、統一がスキルの挙動に与える影響は brainstorming で詰める。
