# j-recap スキル（作業成果の外部向けまとめ）を新規作成

## 概要

指定期間（デフォルト=今日）の作業成果を、episodic-memory の会話記録から拾い、**タスク単位で「進捗ステータス＋概要」**にまとめ、**外部公開できる文章**（X 投稿レベル）としてチャットに出力する user-invocable スキル `/j-recap` を作る。

## 背景

会話記録の要約だけでは「実際に何が完了したか」を取りこぼす（設計まで見えても実際は PR マージ済み、という食い違いが起きる）。そこで **記録で全体像を拾い、git / PR の実体で裏取りしてステータスを確定する2段構え**を核心に据える。既存の `j-log`（内部再現ログ）や `j-doc`（社内ドキュメント）と異なり、**読み手が社外／第三者**である点が本質。

## 成果物

- `dotfiles/.claude/skills/j-recap/SKILL.md`
- 出力は「短文ポスト版」＋「まとめ段落版」の2種、チャットのみ（永続化なし）
- 内部識別子（TASK-ID・内部リポ名など）はサニタイズ

詳細設計は本タスクに紐づく design ノートを参照。
