# j-task の overview-level を実効化する

## 概要

`j-task` は「詳細は brainstorming に送る」と定めているが、**実効性のあるガードが無く、
実際には起票時に詳細が書き込まれている。** ガードを足す。

## 背景

2026-09-02、fde の `tasks/027` で本文が **7,455 B** になった（本リポジトリの同種タスク
`003-j-recap-skill` は 1,447 B）。原因は**既存タスクの粒度に引きずられた**ことである。

タスク本文に分析・引用・トレードオフを書くと、**着手側が起票時点の解釈に縛られ、
認識齟齬が混入する。** 起票者の読み筋が、要件そのものであるかのように残ってしまう。

## 足すもの（案）

- 分量の目安
- 節構成の規定
- **「既存タスクの粒度に合わせない。スキルの規定が優先」の明記**（今回の逸脱の直接原因）
- 悪い例

詳細は brainstorming で詰める。
